- Selected a color theme.

- Completed the Emotion Detector challenge.

## Key Learnings
- Headlines can influence readers through wording and framing.
- Emotional language can be used to manipulate audience reactions.
- Rewriting headlines in a neutral way can improve media integrity.
- Media integrity metrics can help identify potential manipulation.
- Different scenarios can produce different integrity scores.
