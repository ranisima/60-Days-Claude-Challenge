# Day 35 – Prompt Puzzle Assignment

## Step 1: Read the Provided Resources
- Read all the resources provided for Day 35.
- Understand the Prompt Puzzle application and assignment requirements.

## Step 2: Watch the Solution Video
- Watch the complete solution video.
- Note how the application is created and used.

## Step 3: Open Claude
- Open [Claude](https://claude.ai/).
- Sign in to your account.

## Step 4: Set Claude Effort Level to Low
- Open the Claude effort settings.
- Select **Low**.

## Step 5: Paste the Prompt Puzzle Prompt
- Start a new Claude conversation.
- Copy the provided **Prompt Puzzle prompt**.
- Paste the complete prompt into Claude.

## Step 6: Answer the Two Onboarding Questions
- Read the two questions asked by Claude.
- Provide the required answers.
- Continue to the application generation stage.

## Step 7: Generate the Complete HTML Application
- Ask Claude to generate the complete Prompt Puzzle application.
- Wait for the full HTML code to be generated.
- Make sure all required features are included.

## Step 8: Save the HTML File
- Copy the generated HTML code.
- Open Notepad or VS Code.
- Paste the code.
- Save the file as:

`prompt-puzzle.html`

- Make sure the file extension is `.html`, not `.txt`.

## Step 9: Open the Application Locally
- Locate `prompt-puzzle.html`.
- Double-click the file or open it with Chrome.
- Check that the application loads correctly.
- Test the buttons and interactive features.

## Step 10: Play Through All Three Challenges
- Complete **Challenge 1**.
- Complete **Challenge 2**.
- Complete **Challenge 3**.
- Review the results after each challenge.

## Step 11: Review the Prompt Performance Report
- Open the **Prompt Performance Report**.
- Review your score and feedback.
- Note your strengths and areas for improvement.
- Take a screenshot of the report.

## Step 12: Replay Using Another Domain or Difficulty
- Use the replay option.
- Select a different domain or difficulty.
- Complete another round.
- Confirm that the application works with the new selection.
