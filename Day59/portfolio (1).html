About

I'm a JavaScript developer based in Delhi, currently splitting my time between client projects, open-source contributions, and side projects that push my React and Node.js skills a bit further each time.

I like the part of a project where a rough prototype turns into something people actually rely on — smooth interactions, sensible loading states, code that survives contact with real users. That polish is where most of my recent projects live.
