# Day 29 – Operation Lifeline Assignment Guide

## Step 1: Read the Resources
- Read all the provided Day 29 resources carefully.
- Understand the assignment requirements.

---

## Step 2: Watch the Solution Video
- Watch the complete solution video.
- Observe the workflow before beginning.

---

## Step 3: Open Claude
- Open Claude AI in your browser.
- Sign in to your account.

---

## Step 4: Set Claude Effort Level
- Set the **Effort Level** to **Low**.

---

## Step 5: Start a New Conversation
- Click **New Chat**.
- Do not continue an old conversation.

---

## Step 6: Paste the Operation Lifeline Prompt
- Copy the provided **Operation Lifeline** prompt.
- Paste it into Claude.
- Submit the prompt.

---

## Step 7: Generate the Complete React HTML Application
- Wait for Claude to generate the complete application.
- Ensure the application includes:
  - React-based UI
  - Random company profile generation
  - Supply chain crisis simulator
  - Supplier negotiation system
  - CEO leadership questions
  - AI investment selection
  - Executive dashboard
  - Responsive design

If Claude stops before completing the code, type:

> Continue from where you stopped and complete the remaining code.

---

## Step 8: Save the HTML File
- Copy the generated code.
- Open VS Code or Notepad.
- Paste the code.
- Save it as:

```text
operation-lifeline.html
```

---

## Step 9: Open the Simulator
- Open the HTML file in your browser.
- If required, use **VS Code Live Server**.

---

## Step 10: Start the Simulation
- Click **Start Simulation**.

---

## Step 11: Review the Company Profile
Analyze the randomly generated company details:
- Industry
- Revenue
- Company size
- Supplier network
- Risk level

---

## Step 12: Analyze the Supply Chain Crisis
Review:
- Crisis type
- Business impact
- Timeline
- Operational risks

---

## Step 13: Choose Three Crisis Response Actions
Select any **three** response strategies.

Examples:
- Diversify suppliers
- Increase inventory
- Emergency logistics
- Alternative sourcing
- Manufacturing shift

---

## Step 14: Complete Supplier Negotiation Rounds
Complete every supplier negotiation.
Aim to:
- Reduce delays
- Control costs
- Improve supplier relationships

---

## Step 15: Answer CEO Leadership Questions
Answer every leadership question presented during the simulation.

---

## Step 16: Select Two AI Supply Chain Investments
Choose any **two** AI technologies.

Examples:
- AI Demand Forecasting
- Inventory Optimization
- Predictive Analytics
- Supplier Risk Monitoring
- Route Optimization

---

## Step 17: Review the Executive Dashboard
Review:
- Overall business score
- Profitability
- Customer satisfaction
- Supply chain resilience
- Sustainability score
- AI impact

---

## Step 18: Replay the Simulation
Run the simulation again.
Choose different decisions and compare the results.

---

## Step 19: Take Screenshots
Capture screenshots of:
- Home screen
- Company profile
- Crisis scenario
- Response actions
- Negotiation rounds
- CEO leadership questions
- AI investment selection
- Executive dashboard
- Final results

---

## Step 20: If Claude Stops Generating
If usage limits are reached:
- Wait for the reset period.
- Return to the same conversation.
- Type:

> Continue generating the remaining HTML code.

---

## Step 21: Create a Day29 Folder
Create the following folder in your GitHub repository:

```text
Day29/
```

---

## Step 22: Create `day29.md`
Inside the **Day29** folder, create:

```text
day29.md
```

Include:
- Project title
- Objective
- Features
- Key learnings
- Challenges
- Screenshots
- HTML file

---

## Step 23: Upload Project Files
Upload:
- `operation-lifeline.html`
- `day29.md`
- All screenshots

---

## Step 24: Commit and Push

```bash
git add .
git commit -m "Completed Day29 Operation Lifeline Simulator"
git push origin main
```

> Replace `main` with your branch name if different.

---

- Open your GitHub repository.
- Open the latest commit.
- Copy the commit URL.
- Submit it on the assignment portal.
