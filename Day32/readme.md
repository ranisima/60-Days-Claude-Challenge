# Day 32 Assignment Guide – Marketing Strategy Simulator

## Step 1: Read the Resources
- Read all the provided Day 32 resources carefully.

## Step 2: Watch the Solution Video
- Watch the complete solution video to understand the expected output.

## Step 3: Open Claude
- Open Claude in your web browser.
- Log in to your account.

## Step 4: Set Claude Effort Level
- Set the **Effort Level** to **Low**.

## Step 5: Start a New Conversation
- Click **New Chat**.
- Do not continue a previous conversation.

## Step 6: Paste the Marketing Strategy Simulator Prompt
- Copy the prompt provided in the resources.
- Paste it into Claude.
- Press **Enter**.

## Step 7: Generate the HTML Application
- Wait for Claude to generate the complete HTML application.

## Step 8: Save the HTML File
- Copy the generated code.
- Open **Notepad** or **VS Code**.
- Paste the code.
- Save it as:

```text
marketing-strategy-simulator.html
```

## Step 9: Open the Application
- Double-click the HTML file.
- It will open in your default web browser.

## Step 10: Choose a Mode
Select one of the following:
- Business
- Personal Brand
- Random Client

## Step 11: Understand the Target Audience
Review the generated audience profile, including:
- Age group
- Interests
- Pain points
- Goals

## Step 12: Select Marketing Platforms
Choose the most suitable platforms, such as:
- Instagram
- Facebook
- LinkedIn
- YouTube
- TikTok
- X (Twitter)
- Pinterest
- Email Marketing

## Step 13: Choose Three Content Pillars
Select any three content pillars.

Example:
- Educational
- Promotional
- Behind the Scenes

## Step 14: Generate the 30-Day Marketing Roadmap
- Generate the complete roadmap.
- Review the daily content schedule and marketing strategy.

## Step 15: Respond to the Random Marketing Event
- Read the generated marketing challenge.
- Choose the best response.
- Continue the simulation.

## Step 16: Review the Final Growth Report
Study the report, including:
- Reach
- Engagement
- Followers
- Leads
- Sales
- Overall Growth Score

## Step 17: Study the Reusable Claude Prompts
- Review the reusable Claude prompts shown after each section.
- Understand how they can be reused.

## Step 18: Replay the Simulator
Run the simulator again using different options, such as:
- Local Restaurant
- Clothing Brand
- Fitness Coach
- Real Estate Agent
- Personal Brand

Compare the outcomes.

## Step 19: Take Screenshots
Capture screenshots of:
- Home Screen
- Mode Selection
- Target Audience
- Marketing Platforms
- Content Pillars
- 30-Day Roadmap
- Marketing Event
- Final Growth Report

## Step 20: Claude Usage Limit
If Claude reaches its usage limit:
- Wait for the reset period.
- Resume the assignment afterward.
