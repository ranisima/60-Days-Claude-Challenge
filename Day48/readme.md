# Day 48 — The Verdict Engine: Step-by-Step Guide

## Step 1: Read the Provided Resources

Read all the resources provided for Day 48 carefully so you understand the objective and requirements.

## Step 2: Watch the Solution Video

Watch the complete solution video and observe how the **The Verdict Engine** application is built and used.

## Step 3: Open Claude

Open Claude in your browser.

## Step 4: Set Claude Effort Level to Low

Set the **Claude effort level to Low** before starting the task.

## Step 5: Start a New Conversation

Start a **new conversation** in Claude.

## Step 6: Paste the The Verdict Engine Prompt

Copy and paste the provided **The Verdict Engine** prompt into the new Claude conversation.

## Step 7: Answer Claude's Interview Questions

Answer all of Claude's interview questions clearly and completely.

## Step 8: Generate the Complete HTML Application

Generate the complete **The Verdict Engine HTML application** based on the prompt and your answers.

## Step 9: Save the Generated HTML File

Save the generated application as an `.html` file.

```text
the-verdict-engine.html
```

## Step 10: Open It Locally in Your Browser

Open the saved HTML file in your browser and verify that the application works correctly.

## Step 11: Adjust Criteria Weights

Change the **criteria weights** and observe how the ranking updates live.

## Step 12: Review the Sources Panel

Open the **Sources** panel and review the sources associated with every data point.

## Step 13: Review "How This Was Researched"

Open the **"How this was researched"** panel and review:

* Research methodology
* Sources used
* Conflicts identified
* How conflicts were resolved
* Important research notes

## Step 14: Take Screenshots

Take clear screenshots of the completed application.

Recommended screenshots:

* Main dashboard
* Criteria weights and live ranking
* Sources panel
* "How this was researched" panel
* Final verdict/ranking

## Step 15: Create a Day48 Folder

Open your GitHub repository and create:

```text
Day48
```

## Step 16: Create `day48.md`

Inside the `Day48` folder, create:

```text
day48.md
```

Include:

* Project name
* What you built
* Key features
* Testing performed
* Key learnings

## Step 17: Upload Required Files

Upload the following to the `Day48` folder:

```text
Day48/
├── day48.md
├── the-verdict-engine.html
├── screenshots/
│   ├── dashboard.png
│   ├── ranking.png
│   ├── sources.png
│   └── research.png
├── sourced-data-report
└── key-learnings
```

Make sure the screenshots, generated HTML file, sourced data report, and key learnings are included.

## Step 18: Commit and Push the Changes

Commit your changes with a clear message:

```text
Add Day 48 - The Verdict Engine
```

Then push the changes to GitHub.

## Step 19: Submit the GitHub Commit URL

Open the newly created GitHub commit, copy its **commit URL**, and submit it as your Day 48 submission.
