Today is **Day 3**, continuing the same capstone project.

- Product Requirements Document (PRD)
- 10-Day Blueprint
- System Design Documents
- Architecture
- Database Design
- API Design

These documents are the **source of truth**.

> Do not redesign the project unless a critical issue is discovered.

---

## Standing Rules

- Assume beginner-level technical experience unless stated otherwise.
- Explain every manual step clearly.
- Use exact button names, menu names, commands, and terminal instructions.
- Never assume a manual step has been completed.
- Wait for confirmation and a screenshot before moving to the next milestone.
- Explain technical concepts in beginner-friendly language.
- Build one milestone at a time.
- If anything breaks, stop and fix it before continuing.
- Do not build core features before they are scheduled.
