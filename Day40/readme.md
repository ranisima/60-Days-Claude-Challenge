# Day 40 — AI Assistant Builder

- [ ] **1. Read the provided resources**
  - Read all the resources provided for Day 40.
  - Understand the AI Assistant Builder requirements.

- [ ] **2. Watch the solution video**
  - Watch the complete solution video.
  - Note the important steps and features.

- [ ] **3. Open Claude**
  - Open Claude in your browser.
  - Sign in if required.

- [ ] **4. Set Claude effort level to Low**
  - Set the Claude effort level to **Low**.

- [ ] **5. Start a new conversation**
  - Start a fresh Claude conversation.

- [ ] **6. Paste the AI Assistant Builder prompt**
  - Copy the provided AI Assistant Builder prompt.
  - Paste it into the new Claude conversation.

- [ ] **7. Answer Claude's interview questions**
  - Complete Claude's interview questions.
  - Use the **MCQ quiz form**.
  - Do **not** type free-form answers.
  - Select the appropriate options.

- [ ] **8. Generate the complete HTML application**
  - Generate the complete HTML application.
  - Make sure the assistant, system prompt, and documentation panel are included.

- [ ] **9. Publish the Claude artifact**
  - Prefer publishing the Claude artifact using the dropdown/publish option.
  - Run the assistant inside **Claude.ai / Claude apps**.
  - No Anthropic API key is required in the Claude environment.
  - The API request to `api.anthropic.com` is handled automatically.

- [ ] **10. Understand the downloaded HTML requirement**
  - If you download the HTML and open it in a browser, you will need a real Anthropic API key for live Claude API calls.
  - The same applies if you host the HTML on your own website.
  - Never expose or upload a real API key to GitHub.

- [ ] **11. Test your assistant**
  - Open the published artifact.
  - Test the assistant with different questions/tasks.
  - Confirm that it responds correctly.
  - Check for errors.

- [ ] **12. Review the generated system prompt**
  - Open the generated **System Prompt**.
  - Review the assistant's role, behavior, instructions, and response style.
  - Save/copy the system prompt for submission.

- [ ] **13. Explore the documentation panel**
  - Open the **Documentation** panel.
  - Review the available documentation.
  - Explore the usage instructions and implementation details.

- [ ] **14. Take screenshots**
  - Capture screenshots of:
    - AI Assistant Builder
    - Completed MCQ interview
    - Generated assistant
    - Published artifact
    - Assistant test results
    - System prompt
    - Documentation panel

- [ ] **15. Create a Day40 folder in your GitHub repository**
  - Create a folder named `Day40`.

- [ ] **16. Create a `day40.md` file**
  - Create `day40.md` inside the `Day40` folder.
  - Add:
    - Project title
    - What you built
    - Testing details
    - System prompt information
    - Documentation explored
    - Key learnings

- [ ] **17. Upload screenshots, generated HTML file, system prompt, and key learnings**
  - Upload screenshots.
  - Upload the generated HTML file.
  - Upload the system prompt.
  - Add key learnings to `day40.md`.
  - Do not upload any API keys or secret credentials.

- [ ] **18. Commit and push the changes**

  - Commit the changes with a meaningful commit message.
  - Push the changes to GitHub.
