# Day 20 – Face Puzzle Game

## Objective
Created an interactive Face Puzzle Game using Claude AI. Generated an HTML application that captures a photo using the webcam and converts it into a playable puzzle.

## Activities Completed
- Generated the Face Puzzle Game HTML application.
- Saved and tested the HTML file.
- Allowed webcam access.
- Captured a photo.
- Selected puzzle difficulty.
- Played the puzzle game.
- Tested drag-and-drop interactions.
- Verified touch support.
- Tested timer, move counter, and leaderboard.
- Completed the puzzle successfully.

## Features Tested
- Webcam Capture
- Photo-Based Puzzle Generation
- Difficulty Levels (3×3, 4×4, 5×5)
- Drag-and-Drop
- Touch Support
- Timer
- Move Counter
- Leaderboard

## Key Learnings
- Learned how AI can generate complete browser-based games.
- Understood webcam integration using HTML, CSS, and JavaScript.
- Explored drag-and-drop game mechanics.
- Learned how timers and leaderboards improve user engagement.
- Experienced AI-assisted rapid web application development.
