### Setup and Generation
* Watch the solution video for a clear overview.
* Open [Claude](https://claude.ai) in a new window.
* Set your effort level to Low.
* Paste the Task Compass prompt in a new chat.
* Pick a workplace type and generate the code.
* Save the output as an HTML file.

### Testing and Stages
* Double-click the file to open it in your browser.
* Finish Stage 1: Who Owns This?
* Finish Stage 2: Task Routing.
* Finish Stage 3: Collaboration Challenge.
* View your final Organizational Thinking Dashboard.
* Repeat the steps with a second workplace type.
* Take screenshots of your progress and dashboard.

### GitHub Submission
* Make a new folder named `Day37` in your repository.
* Add a new file named `day37.md`.
* Upload your screenshots, HTML file, and notes.
* Commit your changes and push them to GitHub.
* Copy the commit link for your final submission.
